# Последняя рабочая версия сайта «Релайн» — 21 октября 2026

Это комплект для переноса проекта на другой компьютер: HTML, CSS, JavaScript, все изображения сайта, исходные PNG иллюстраций, заметки и инструкция для Codex.

## Как продолжить на другом компьютере

1. Скачайте и распакуйте архив целиком.
2. Откройте в Codex распакованную папку, в которой находятся `index.html`, `ospt-reline-static`, `wp-content` и этот файл.
3. Передайте Codex текст:

   «Это текущая рабочая версия сайта Релайн. Прочитай START_HERE_RU.md и transfer-notes/HANDOFF_CONTEXT_RU.md. Продолжай работу с этими файлами. Сейчас нужно завершить пасхалку со стариком на причале: проверить размер, положение, наведение на газету и переход на существующую страницу О компании. Не публикуй незавершённые правки без проверки».

История чата сама по себе в архив не переносится. Контекст для продолжения записан в `transfer-notes/HANDOFF_CONTEXT_RU.md`.

## Что здесь находится

- `ospt-reline-static/index.html` — главная рабочая страница с 3D-панорамой и плюсами.
- `ospt-reline-static/` — страницы объектов, включая судовые резервуары и корпус судна.
- `wp-content/themes/reline/assets/` — CSS, JavaScript, шрифты, изображения и сохранённые старые варианты.
- `about/index.html` — существующая страница «О компании».
- `design-sources/` — все доступные непустые PNG, созданные генератором изображений в этом рабочем чате. Сайт использует оптимизированные изображения из `assets/img`.
- `transfer-notes/` — контекст и записанные промпты иллюстраций.
- `PREVIEW.py` — локальный просмотр без сторонних библиотек.

Это статическая версия сайта, которая публикуется на GitHub Pages. WordPress-сервер и база данных для работы с этой версией не нужны.

## Локальный просмотр

При наличии Python запустите из этой папки:

```sh
python PREVIEW.py
```

Затем откройте `http://127.0.0.1:8000/ospt-reline-static/`.

Скрипт подставляет локальные адреса вместо адресов опубликованного сайта только в ответах локального сервера; исходные файлы не переписывает. Для другого порта: `python PREVIEW.py 8080`.

Снимок для переноса не заменяет опубликованную ветку. Продолжать редактировать файлы можно сразу после распаковки. Перед публикацией Codex должен проверить различия между `transfer-20261021` и `gh-pages`.

Если на новом компьютере установлен Git, вместо ZIP можно получить файлы вместе с историей:

```sh
git clone --branch transfer-20261021 https://github.com/enanro/relain-site.git relain-site
```

Архив, скачанный кнопкой GitHub, не содержит скрытую папку `.git`. Локальный полный архив, подготовленный рядом с этим файлом на исходном компьютере, включает `.git` и историю.
